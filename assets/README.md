# Assets

This folder contains public-safe diagrams for the CMMS mobile PWA documentation.

- `cmms-pwa-architecture.svg` - Main architecture overview.
- `offline-sync.svg` - Offline draft and sync workflow.
- `payment-flow.svg` - Internal payment boundary and webhook flow.
- `token-governance.svg` - API token and AI token governance.
- `pwa-platform-architecture.svg` - Expanded platform architecture.
- `mobile-field-workflow.svg` - Technician field workflow.
- `offline-sync-state-machine.svg` - Queue state and sync transitions.
- `pwa-cache-strategy.svg` - Route and asset cache behavior.
- `payment-entitlement-flow.svg` - Billing event and entitlement flow.
- `api-token-lifecycle.svg` - API token creation, verification, rotation, and revocation.
- `ai-usage-governance.svg` - AI gateway, budget, and usage controls.
- `data-model-map.svg` - High-level record relationships.
- `role-based-surfaces.svg` - Role-specific product surfaces.
- `failure-modes-recovery.svg` - Common failure modes and recovery actions.
- `launch-readiness-scorecard.svg` - Public-safe launch readiness illustration.

## Public-Safety Notes

These assets use generic labels only. They should not include tenant IDs, production URLs,
credentials, payment identifiers, provider keys, private emails, customer names, or real
operational records.
