# Assets

This folder contains public-safe diagrams for the CMMS mobile PWA documentation.

## Published Assets

- `cmms-pwa-architecture.svg` - Main architecture overview.
- `offline-sync.svg` - Offline draft and sync workflow.
- `payment-flow.svg` - Internal payment boundary and webhook flow.
- `token-governance.svg` - API token and AI token governance.

## Public-Safety Notes

These assets use generic labels only. They should not include tenant IDs, production URLs,
credentials, payment identifiers, provider keys, private emails, customer names, or real
operational records.
